# 个人购物决策

面向中国大陆个人消费者的 Codex Skill：把“买什么、值不值、怎么比、何时买、要不要盯价”变成可解释、可核验的建议，适合希望依据预算、用途和公开证据做决定的人。

## 1. 定位与适用人群

面向中国大陆个人消费者的 Codex Skill：把“买什么、值不值、怎么比、何时买、要不要盯价”变成可解释、可核验的建议，适合希望依据预算、用途和公开证据做决定的人。

## 2. 五种能力与不支持范围

Skill 每次只选择一个主要模式：

| 模式 | 用途 |
| --- | --- |
| `recommend` | 按预算、用途和硬性条件推荐 2–4 个候选 |
| `evaluate` | 判断一个准确商品和卖家是否适合 |
| `compare` | 比较可互相替代的准确商品 |
| `price-timing` | 核验当前总成本、历史参考并给出条件化的购买时机建议 |
| `monitor` | 在完整授权后建立降价监控合同 |

不处理泛泛的商品科普、维修、售后纠纷、卖家侧电商、个人对个人二手交易；对药品、医疗器械、金融、房产、汽车整车和旅游预订只整理公开信息与风险，不给出购买结论。不能承诺所有渠道中的价格最低，也不会把搜索摘要或营销页当作已核验价格。

## 3. 自动触发与显式调用

当对话明确涉及推荐、单品是否值得买、多商品比较、当前价格或购买时机，或明确要求持续关注价格时，Skill 可自动触发。也可显式调用：

```text
$shopping-decision：预算 3000 元，推荐适合长辈使用的手机。
$shopping-decision：比较这两款商品，并判断现在是否值得买。
$shopping-decision：低于目标总成本时提醒我。
```

自动触发和显式 `$shopping-decision` 调用遵循同一边界；一次任务只确定一个主要模式。

本仓库包含 `.codex-plugin/plugin.json`，可作为 Codex 插件包发布。仓库推送发布后，在 Codex 的插件管理入口添加该 GitHub 仓库（或将其加入你的个人插件市场后安装），然后启用 `shopping-decision-skill`。插件安装路径由 Codex 的插件管理流程处理；不要把上面的 Skill 安装命令误作插件发布或安装操作。

## 5. 本地偏好档案

偏好档案默认关闭，只有你主动选择本地路径并确认后才会创建或读取。可保存的字段仅包括省/市级地区、品类预算、品牌或平台偏好/排除项、是否接受可核验官方翻新或第三方卖家、决策权重、你主动保存的尺码/合身信息，以及每项的最后确认日期。

创建、修改和删除都先展示路径或字段范围，并取得确认；当前对话中的信息优先于档案。你可随时要求删除指定字段或整个本地档案，删除前会再次确认。不会自动记录浏览或购买历史，也不保存账号、密码、Token、支付数据、证件、精确住址或完整地址。

## 6. 降价监控

降价监控必须由你明确授权，并在创建前确认完整的七项条件：准确商品版本、目标条件（含目标价格）、可用平台、可用卖家类型、检查频率、结束日期和通知字段。缺少任一项不会创建或继续监控。

只有确认完整条件且运行环境支持时，才会使用环境提供的原生定时/自动化机制；本仓库不自带调度脚本或替代调度文本。通知至少包含价格、库存、卖家类型、查询时间、来源，以及是否满足全部条件；到结束日期、授权撤回或条件不完整即停止。监控不登录、不加购、不结算、不下单，也不付款。

## 7. 价格证据与覆盖

价格核验先锁定品牌、型号、代际、容量/尺寸、套装、成色和卖家。每条已核验记录会说明卖家类型、库存、基础价、条件优惠、运费、总成本、证据等级、来源和查询时间（中国标准时间）。仅无登录即可复查的 A/B 级公开页面可支撑当前价格或总成本结论；历史价仅作参考。

输出会列出未访问渠道、登录墙、地区差异、库存/运费缺失、未验证优惠资格、不可比变体和查询时间差等覆盖缺口。因此结论只适用于已核验渠道与页面，不外推为全网结论。

## 8. 隐私与不购买边界

Skill 只帮助决策：不登录、不操作购物车、不结算、不下单、不付款，也不索取或处理敏感凭据。遇到需要登录、支付、下单、个人对个人二手交易、售后争议或法律纠纷时，会停止购买判断并给出安全的下一步。高风险品类仅提供公开信息整理与风险提示。
