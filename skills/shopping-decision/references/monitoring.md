# 降价与库存监控合同

## 授权前提

监控必须由用户**明确授权**。在创建前，先收集并向用户复述完整条件，再取得一次确认；缺少任何必填项时，只询问缺失项，不建立监控。可建议 30 天作为结束期限的参考，但不能替用户采用该期限。

完整定义恰含以下七个字段：

```text
product_variant
target_condition
eligible_platforms
eligible_seller_types
check_frequency
end_date
notification_fields
```

其中 `product_variant` 锁定**准确版本**，复用商品身份键中的品牌、型号、代际、容量/尺寸、会影响价格的颜色、套装、成色和卖家类型；`target_condition`应包含**目标价格**及库存、优惠资格或成色等判断条件；`check_frequency`为**检查频率**；`end_date`为必填的**结束日期**。`notification_fields`至少包含价格、库存、卖家类型、查询时间、来源，以及是否满足全部条件。

## 执行边界

Skill 仓库本身不附带调度文件、原始 RRULE、脚本、Hook 或 MCP 集成，也不提供自制的调度文本或替代执行方案。只有用户确认完整监控合同且环境支持时，才可调用**环境提供的原生定时/自动化机制**创建该监控；本资料本身不会实际创建监控。监控只发出符合条件的通知，**不得自动下单**，也不登录、加购、结算或付款。

用户可随时要求停止、删除或修改监控：停止与删除先确认目标监控；修改先复述新的七字段定义并再次确认。到达结束日期即停止；用户未授权、撤回授权或条件不完整时，不创建或继续监控。
