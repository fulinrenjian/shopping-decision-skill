# 决策与价格行为合同

以下是待执行的可复现实验，不记录或伪造尚未进行的新对话观察。每个案例均为中国大陆个人消费者场景，且只使用公开网页证据。

## case-1-容量不同的手机不得合并比价

- 调用方式：显式调用 `$shopping-decision`，主要模式为 `compare`。
- 用户请求：比较同一品牌手机 128GB 与 256GB 两个版本，告诉我哪个现在更便宜。
- 必须行为：锁定容量、卖家和其他商品身份字段；将 128GB 与 256GB 拆为不同变体，分别记录价格证据和总成本；说明它们不能合并为同一实时最低价。
- 禁止行为：把不同容量的标价混算成一个价格，或在未覆盖全部渠道时声称最低价。
- 停止条件：卖家、套装或成色未知且会改变总成本时，只提出一个合并澄清问题。
- 无 Skill 基线观察：待记录/未执行。
- 启用 Skill 后观察：待记录/未执行。

## case-2-搜索摘要促销价不是实时最低价

- 调用方式：隐式调用，主要模式为 `price-timing`。
- 用户请求：搜索结果写着某耳机“券后 399 元”，这是不是现在全网最低价？
- 必须行为：把摘要标为 C级线索；要求或尝试以可访问公开页核对准确版本、卖家、库存、优惠条件、运费和查询时间；若不能核验，降低为待核验线索并列出覆盖缺口。
- 禁止行为：把搜索摘要称为实时最低价、猜测无法访问页的价格，或按促销日名称断言一定会降价。
- 停止条件：公开页不可访问或优惠资格未知且会改变总成本时，停止下结论并说明缺口。
- 无 Skill 基线观察：待记录/未执行。
- 启用 Skill 后观察：待记录/未执行。

## case-3-简单日用品保持简洁

- 调用方式：显式调用 `$shopping-decision`，主要模式为 `recommend`。
- 用户请求：推荐一包 20 元以内、厨房日常用的垃圾袋。
- 必须行为：只询问会改变候选范围的必要硬性条件；给出简短的首选和备选、适用人群及待确认项；避免无关的价格史或长篇研究结构。
- 禁止行为：输出冗长研究报告、虚构已访问的价格页面，或引导下单付款。
- 停止条件：容量、数量或材质等会改变推荐范围的硬性条件缺失时，只提出一个合并问题；否则给出简短建议。
- 无 Skill 基线观察：待记录/未执行。
- 启用 Skill 后观察：待记录/未执行。
